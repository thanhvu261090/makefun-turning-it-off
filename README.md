## Why this line

The brief asks for the hopeless tech support agent's signature move: the reboot. The joke lands on the agent's total lack of shame about it — the reboot isn't step one of a real diagnosis, it is the whole qualification, and the meter is still running. The customer is desperate, the agent is relaxed, and the power button is doing all the work.
